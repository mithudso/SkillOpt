commands and the current audit receipts; historical results are not current
provider or security attestations.

- Start with [installation](../INSTALLATION.md), [onboarding](../onboarding.md)
  and [development](../DEVELOPMENT.md).
- Read [architecture](../ARCHITECTURE.md), [components](../COMPONENTS.md),
  [requirements](../requirements.md) and the [file map](../codebase-overview.md).
- Check [tests](../TESTING.md), [security boundaries](../SECURITY.md),
  [logging](../logging.md) and [caching](../caching-and-optimization.md).
- Find [MCP adapters](../MCP.md), [external calls](../external-calls.md) and
  [integration assumptions](../integrations-and-assumptions.md).
- Use the [maintenance runbook](../runbooks/maintenance.md) for synthetic
  verification, delivery and recovery. See [known issues](../known-issues.md) for
  limits that a source pass does not settle.

The October 5 [bootstrap report](../repo-bootstrap-audit-2026-10-05.md) is a
historical additive pass. It explicitly did not run source optimization. New
maintenance reports must state their full source coverage and independent-review
limits; do not infer completion from that older report.
