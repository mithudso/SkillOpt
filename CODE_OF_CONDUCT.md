# Contributor conduct

Keep technical discussion respectful and evidence-based. Critique the work, avoid
personal attacks and harassment, and respect other contributors' privacy. Do not
publish credentials, private transcripts or customer data in issues or reviews.

The personal fork's maintainer may moderate abusive public content and restrict
participation to keep collaboration safe. Report a conduct concern privately to
the maintainer using an available private GitHub channel; do not expose another
person's private information in a public report. The upstream project retains its
own policies. This file adds no service commitment or license grant.
